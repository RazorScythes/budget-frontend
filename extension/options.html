Extension settings

Connect the extension to your Budget Manager account using a personal client key.

Connection

Set automatically from your build (localhost in dev, production URL in release). You can override if needed.
Generate this in Budget → Settings → Tools. Required for production. On localhost you can leave it empty when the backend has DEVELOPMENT=true.

How it works

  • Each user gets a unique bext_… client key
  • The key signs requests — server secrets stay on the backend
  • You can revoke or regenerate the key anytime

Security

  • Client keys belong to your account only
  • Login fails if the key does not match your username
  • Never share your client key or commit it to git
